# GLEON Seminal papers

This repository contains some of the work of the GLEON Seminal Papers group. 

### How to run the code 
- Download or fork the code.
- Upload a copy of the *Literature data.xlsx* file to the **Data folder**.
- Run the code
- Enjoy

### What the code does 
The code pulls data for all the papers through its DOI. The data is pulled from CrossRef through the CrossRef R-package.
